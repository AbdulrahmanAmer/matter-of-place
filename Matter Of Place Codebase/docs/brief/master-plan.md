# MATTER OF PLACE

## MASTER WEBSITE BUILD PROMPT

Build the complete first version of **MatterOfPlace.com**.

Matter of Place is a global real-estate media exposure and property discovery company under the Omnikom ecosystem.

This is **not a brokerage website**.

This is **not an MLS portal**.

This is **not a generic luxury real-estate marketplace**.

This is **not a proptech SaaS website**.

This is a selective global property media platform built to discover, present, amplify and create attention around extraordinary real estate.

The commercial model takes inspiration from selective editorial real-estate publications such as The Full Ask: exceptional properties are presented with editorial discipline, social-media distribution, dedicated property pages, direct inquiry paths, and paid amplification opportunities.

The emotional and visual discipline should take inspiration from the restraint, spatial calm, confidence and sense-of-place philosophy associated with Aman.

Do NOT copy either company.

Synthesize the principles into an original Matter of Place identity.

---

# 1. CORE BRAND IDEA

Matter of Place begins from a simple belief:

**A property is more than an asset.**

A home is not just:

- square footage
- price
- cap rate
- bedrooms
- investment return
- an address
- a transaction

It is a place someone inhabits.

It carries:

- geography
- architecture
- atmosphere
- privacy
- light
- landscape
- history
- context
- emotion
- permanence
- identity

The name **Matter of Place** should therefore feel almost like a sentence.

It communicates:

**Place matters.**

The property matters because the place matters.

The platform should make users feel that they are discovering extraordinary places rather than searching a database of inventory.
