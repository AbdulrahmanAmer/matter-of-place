# src/templates

React templates consumed by render jobs, not by pages: social carousel, story and cover templates, the Open Graph image, the newsletter block, and React Email templates under `src/templates/email/`. Templates take their colours and type from the values in `src/styles/tokens.css`, never hex. A new email is a template here plus a row in the `email_templates` seed with its subject and variables (`docs/HOW-TO-ADD.md`).

## Module map

| Path                                    | What it is                                                                                                                                                                                                                                                                                                                                                                                              |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `social/SocialFrame.tsx`                | The shared frame of cover, carousel and story: photograph slot, solid band, wordmark and the text slots (marker, location, headline, price, specs). No logic: a slot that is not given is not drawn.                                                                                                                                                                                                    |
| `social/social.css`                     | Plain CSS for the frame. Every number is a `--social-*` token from `src/styles/tokens.css`; a format only chooses which tokens apply.                                                                                                                                                                                                                                                                   |
| `social/fonts.css`                      | `@font-face` for Jost and Cormorant Garamond (normal and italic) from `public/fonts`.                                                                                                                                                                                                                                                                                                                   |
| `social/fixtures/property.fixture.json` | One full illustrative property (`oak-hill-residence`): facts, five photographs under `src/assets`, and the caption JSON. Used by tests and by the render scripts with `--fixture`.                                                                                                                                                                                                                      |
| `email/style.ts`                        | The one style source of every email: the faces (a class for the brand stack, an inline stack Outlook can draw), the five theme colours by brand name, the measures, the scale, and the four style blocks of the head (web fonts, faces and phone layout, dark mode, motion behind `prefers-reduced-motion`).                                                                                            |
| `email/layout.tsx`                      | The document every email is drawn in (`Shell`: head, preheader, page), the props a template receives, and the closing lines of the plain-text part.                                                                                                                                                                                                                                                     |
| `email/house/*.tsx`                     | The three houses (operator, 2026-10-15): `threshold.tsx` for the moments (full-width shots cut on value, the night door GIF, the row's opening through it), `afternoon.tsx` for correspondence (one Bone wall, the day door GIF, a centred placard), `light.tsx` for internal mail (one Warm Ivory record, the emblem as the door). Each template file picks one and passes its labels and instruments. |
| `email/blocks.tsx`, `email/blocks/*`    | The block model drawn by every house (leading level-1 headings are the opening, level 2 a statement, level 3 a label), and the shared parts: `colophon.tsx` (the same words in every house), `picture.tsx`, `band.tsx`, `stage.tsx` (Threshold's stack), `ledger.tsx` (the invoice's exact amounts).                                                                                                    |
| `email/art.ts`                          | Every picture an email loads from `public/email/` and its display size; the doors come from `launch/email-doors`, the marks from `scripts/email-art.mjs`. `scripts/email-gallery.ts` photographs all twenty emails into `workspace/08-email-redesign/v2/`.                                                                                                                                              |
| `email/newsletter-welcome.tsx`          | The welcome a subscriber gets once after confirming, with its slot for the lead piece of the latest Place Notes issue (its own picture, or the film's house) and the three markets.                                                                                                                                                                                                                     |

## Rules

- The direction is `workspace/08-creative/DIRECTION.md`. A value that changes there changes the `/* social */` block of `src/styles/tokens.css` first, then the template.
- The fonts in `public/fonts` come from `bun run fonts` (`scripts/fonts.mjs`), copied from the `@fontsource-variable/*` packages with their licences. Run it by hand when a package version changes and commit the output with it.
- The fixture property is illustrative. Production shows none.
