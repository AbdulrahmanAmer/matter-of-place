A command is bash run from `app/`; `<dev>`, `<prod-config>`, `<worker>`, `<load-dev>` and `<load-ops>` are replaced before it runs. `<dev>` defaults to `http://localhost:8080` (`H1_DEV_URL`), `<prod-config>` to the Worker of the env (`H1_PROD_CONFIG_URL`).
- Order of the verdict: non-zero exit is `fail`; else a first output line that starts `BLOCKED` is `blocked` (`blocked-on-L1` outside `--env prod` for an L1 row); else a missing `expectOutput` pattern is `fail`; else `pass` (`blocked-on-L1` for an L1 row outside `--env prod`). A row marked `blockedOn: "L1"` with no `command` is `blocked-on-L1` without running anything (H1-30, H1-41).
