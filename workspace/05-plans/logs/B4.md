How the tool differs from the plan's wording, so g2 to g7 are not surprised:
- No `--only` or `--changed` replays everything that is not `kind: "manual"`. `--only <id>` matches the id in every registry file (B1b and B4 both hold `z`, `n`, `d`, `a`); each line is labelled `<registry>:<id>`.
- `--kinds` takes `unit` (every file entry) and `sql`.
- A run may start with `NAME=value` words (`CI=1 bunx playwright test ...`, `RESEND_API_KEY=leak bunx vitest ...`): the tool moves them into the environment, because `shell: true` on this laptop is `cmd.exe`.
- An entry may carry `after`, a command that must exit 0 on the restored file.
- `--record` writes a ledger row for a by-hand run only; a registry replay never writes the ledger.
- Exit codes: 0 ok, 1 BAD, 2 stale (a `find` that occurs other than once, a malformed entry), 64 usage.
