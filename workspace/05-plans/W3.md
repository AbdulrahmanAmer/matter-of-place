## The bar every stage is held to

A person who has never seen the screen does the task by hand on the first try: the page says in words what it is,
what is waiting, and what the next action is; the main action sits at the top; nothing on screen is a database name.
The operator uses a screen reader, so every control has a spoken name and a list view exists wherever a drawing does.
Each stage is screenshotted on the live data (read-only preview harness) before it ships, and sent to the operator.
