# B17 — Website essentials and compliance (the must-haves of any professional site)

Lane: website · Stage: 3 · Owner agent: mop-builder (mop-designer for the icon set, error pages and consent notice) · Depends on: B1b (`src/start.ts` middleware, `headers.ts`, deploy, preview Worker), B3 (events route and the `analyticsEvents` allow-list), B3b (consent library, notice, flags), B4 (Playwright config, axe sweep), B13 (`lhci`, `scripts/check-seo.ts`, and the robots, sitemap, llms and structured-data output this slice tests) · Unblocks: H1 (its checklist verifies every item here)

## Goal and observed exit
Every essential a serious publication site must have is present, measured and enforced, so that a privacy lawyer, a
security scanner, an accessibility auditor and a search engineer each find nothing missing. Observed exit: the
`essentials` test suite passes on the preview URL (`https://pr-<n>.holy-meadow-4327.workers.dev`, E2) and on the local build (`bun run cf:preview`, `http://127.0.0.1:8788`; in this plan `<preview>` means either); `securityheaders.com` grade A; Mozilla Observatory A; Lighthouse
accessibility 100 and best practices 100 on six pages; the consent notice works with and without JavaScript; every
`.well-known` file resolves; RSS validates; the icon set renders on iOS, Android and Windows.

## Contract (inputs, outputs, invariants, events emitted, permissions)
Invariants, grouped. Each is a test in `tests/e2e/essentials.spec.ts` or `tests/unit/essentials.test.ts`.

**A. Security headers (served by the Worker on every response; B1b owns the middleware, this slice owns the values)**
1. `Content-Security-Policy` (report-only first; H1 flips it to enforcing through `flags.csp_enforce`): `default-src 'self'; script-src 'self' <'sha256-...' for each inline script of the page> https://challenges.cloudflare.com <the GA4/GTM hosts>; style-src 'self' <'sha256-...' for each inline style element of the page>; img-src 'self' data: https://media.matterofplace.com (that host exists only once R2 is on, E8); font-src 'self'; connect-src 'self' https://challenges.cloudflare.com <the GA4 hosts> <origin of SUPABASE_URL, for the browser's signed upload PUT in B3>; frame-src https://challenges.cloudflare.com; frame-ancestors 'none'; base-uri 'self'; form-action 'self'; object-src 'none'; upgrade-insecure-requests; report-to csp`. The policy is by hashes and never by nonce (architecture section 13 rule 5, S52): HTML is cached and identical for every visitor, so a per-request nonce would be stale on every cache hit. `inlineHashes(html)` in `headers.ts` computes the SHA-256 of every inline script and style element of a rendered page once, at render on a cache miss, and `cspFor(env, flags, hashes)` builds the finished policy header from them; the middleware passes it in the built response and B3's `cachedResponse` stores that header (`Content-Security-Policy-Report-Only` while report-only, `Content-Security-Policy` once enforcing) with the page's cache entry (F25 d), so a hit and a miss of one page carry the same policy and a hit does no hashing. The other security headers and `x-request-id` are added after the lookup by B1b's middleware and are never stored. A flip of `csp_enforce` is a write to `settings`, which B2's trigger turns into a new `catalog_version` (F25 a), so the next render stores the enforcing header under a new key. The GA4/GTM hosts are in `script-src`/`connect-src` for every visitor (the policy cannot depend on consent without varying the response); nothing loads from them before consent, because the loader is a first-party file that injects the tag only after `readConsent()` says analytics. `Reporting-Endpoints: csp="/api/public/csp-report"`. B1b already ships `Content-Security-Policy-Report-Only` from `cspFor(env, flags)` with the Google Fonts rows; this slice replaces the table values, removes the Google Fonts hosts (step 2), swaps any nonce for the hash list and adds the tests that `cspFor` output carries no Google Fonts host and no `nonce-` source.
2. `Strict-Transport-Security: max-age=31536000; includeSubDomains` until preload day 30; then L1 raises it to `max-age=63072000; includeSubDomains; preload`.
3. `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`, `X-Frame-Options: DENY` (belt and braces with frame-ancestors), `Permissions-Policy: camera=(), microphone=(), geolocation=(), payment=(), usb=(), interest-cohort=()`, `Cross-Origin-Opener-Policy: same-origin`, `Cross-Origin-Resource-Policy: same-site`, `X-DNS-Prefetch-Control: off`.
4. Cache-Control per route class, following architecture section 13 (this slice owns the values, B1b the middleware that applies them): admin, `/api/admin/*`, `/api/hooks/*`, every POST, every write under `/api/public/`, preview-token pages, any response with `Set-Cookie` and every 5xx (the 503 maintenance page included) `private, no-store`; public pages `public, max-age=0, s-maxage=300, stale-while-revalidate=86400` (browser revalidates, edge holds five minutes); 404 and 410 pages `s-maxage=60`; catalog JSON and the feeds `max-age=60` in the browser with the same edge lifetime as pages; `robots.txt`, `sitemap.xml`, `llms.txt`, `llms-full.txt` one hour; fingerprinted assets `public, max-age=31536000, immutable`; bundled `/media/*` one week (`max-age=604800`); R2 photograph variants under content-hashed keys `public, max-age=31536000, immutable` once R2 is on. `Vary: Accept` on image routes. `ETag` on JSON. No public response carries `Vary: Cookie` and none depends on a cookie or a request header (rule 5).
5. No third-party script or font loads before consent, and none at all except GA4/GTM after consent. Google Fonts are replaced by self-hosted WOFF2 with `font-display: swap` and `<link rel=preload>` for the two text faces (GDPR: no font requests to Google from EU visitors).
6. Every external script that survives (GA4 loader) has Subresource Integrity where the vendor supports a versioned URL; otherwise it is proxied through a first-party path with a pinned version.

**B. Privacy, cookies, consent (B3b owns the consent library; this slice owns the policy and the inventory)**
7. Cookie inventory kept in `docs/cookies.md` and rendered on `/cookies`: name, purpose, provider, duration, category (necessary / analytics). At launch the only cookies are the consent choice (`mop_consent`, 12 months, necessary) and Turnstile's; GA4 cookies exist only after consent.
8. Consent model: CCPA opt-out plus GDPR opt-in in one component: default is "no analytics" for everyone; the notice offers Accept / Decline / Settings; Global Privacy Control is honoured as Decline automatically, read in the browser (`navigator.globalPrivacyControl`) after hydration and on the uncached consent endpoint from the `Sec-GPC: 1` header, never in a cached page render; choice stored in the cookie and mirrored to `localStorage`; a "Privacy choices" link in the footer reopens it; consent version bumps when the inventory changes. Works without JavaScript (the notice is server-rendered the same for every visitor, the links are real links; after hydration the browser hides it when the cookie says a choice exists, so the cached HTML never varies by cookie). The no-JS consent GET answers with `Set-Cookie` and a redirect and is therefore never cached (rule 6).
9. No consent wall, no dark patterns: equal-weight buttons, no pre-ticked boxes, no "by continuing you agree".
10. Data subject requests: `/privacy-request` form (B16) posts to `subjects/request` (B3); acknowledgement within 10 days, fulfilment within 45 (CCPA) / 30 (GDPR) tracked in admin.
11. Legal pages (B16): Privacy (with CCPA section, categories, Do Not Sell or Share, GPC statement, retention table, contact), Cookies, Terms for Professionals, Accessibility statement, Imprint block in the footer (entity, address, contact). Last-updated dates on each. Linked from every page's footer.

**C. Accessibility (WCAG 2.2 AA)**
12. `lang="en"` and `dir` on `<html>`; a skip link to `main`; one `h1` per page; landmarks (`header`, `nav`, `main`, `footer`, `aside`); focus visible on every interactive element (2 px Obsidian outline offset 2 px on Bone, Bone on Obsidian); target size ≥ 24 px; colour contrast ≥ 4.5:1 for text (Warm Grey on Ivory is checked and adjusted where it fails); `prefers-reduced-motion` disables drift and fades; forms have labels, described errors, `aria-live` for notices; dialogs trap focus and restore it; images have alt (illustrative galleries use descriptive alt, decorative images empty alt); keyboard operable menu, search, gallery, filters; no content flashing; captions field on the film. axe serious/critical = 0 on every route in CI (B4).

**D. Discoverability and social (B13 owns structured data and sitemaps; this slice owns the rest)**
13. Per page: unique `<title>` (brand once, G-003), meta description 70 to 160 chars, canonical, Open Graph (`og:type`, `og:title`, `og:description`, `og:image` 1200×630 from B9 covers, `og:url`, `og:site_name`, `og:locale`), Twitter card `summary_large_image`, `theme-color`, `article:*` on stories.
14. `robots.txt` (dynamic route, B13), `sitemap.xml` index with pages and image sitemap, `llms.txt`, `llms-full.txt` (all B13's files; this slice only tests B13's output, it creates none of them), an RSS 2.0 feed at `/feed.xml` for properties and stories with autodiscovery `<link>`, JSON Feed at `/feed.json`.
15. Structured data (B13): `Organization` (logo, sameAs, contactPoint), `WebSite` with `SearchAction`, `BreadcrumbList`, `RealEstateListing`/`Residence`, `Article`, `FAQPage`, validated in CI (a test against B13's output, not a new file).
16. Redirects table (B7) and slug history 301s (B3), resolved from the `redirects` and `slug_history` that the catalog snapshot carries (`getCatalog`, mapped once and held in isolate memory; `getPublicState` supplies the version; no table query per request); `410 Gone` for taken-down properties, answered from the same snapshot; trailing-slash and `www` canonicalisation at the edge (one canonical host, apex).

**E. Identity files and icons**
17. Icon set from the emblem: `favicon.ico` (16/32/48), `favicon.svg` (with `prefers-color-scheme` variant), `apple-touch-icon.png` 180, `icon-192.png`, `icon-512.png`, `maskable-512.png`, `mstile-150.png`; `site.webmanifest` (name, short_name, icons, theme and background in Bone/Obsidian, `display: browser`); `browserconfig.xml`.
18. `/.well-known/security.txt` (RFC 9116: Contact admin@, Expires, Preferred-Languages, Canonical, Policy link), `/.well-known/change-password` (redirects to admin sign-in), `humans.txt` (credits, calm), `robots.txt` (B13). `ads.txt` deliberately absent (no ad inventory).
19. Error pages: branded 404 (search from B3's in-Worker index over the snapshot with plural folding, which costs no database query, F25 g; links to markets), 410 (property taken down), 500 (calm, request id shown for support), 503 maintenance page switchable by `settings.flags.maintenance` with `Retry-After`, read through `getFlags` (which is `getPublicState`, memoised 15 seconds) before the HTML cache lookup so the switch is never masked by a cached page, and never stored (5xx); a write to `settings.flags` bumps `catalog_version` by B2's trigger (F25 a); offline notice via a minimal service worker that caches only the shell and the error page (no offline catalog).

**F. Performance and delivery (B4 enforces budgets; this slice implements)**
20. Images: AVIF + JPEG variants, `srcset`/`sizes`, `loading="lazy"` below the fold, `fetchpriority="high"` on the hero, explicit `width`/`height` (no CLS), `decoding="async"`; video poster, `preload="none"`.
21. Fonts: self-hosted, subset to Latin, WOFF2, two faces preloaded, `font-display: swap`, `size-adjust` fallbacks to avoid CLS.
22. HTTP: Brotli (Cloudflare), HTTP/3 on, Early Hints (`103`) for the two fonts and the stylesheet, `preconnect` only to `media.matterofplace.com` and `challenges.cloudflare.com`.
23. JavaScript budget 150 KB (B4), no third-party tag before consent, route-level code splitting (TanStack already), `defer` on everything non-critical.
24. Uptime check (B14), Sentry (B1b), Web Vitals field data sent to first-party `analytics_events` (`web_vitals` event, anonymous) so the audit robot sees real LCP/CLS/INP.

**G. Domain and mail hygiene (L1 and B5 own the records; this slice owns the checklist)**
25. DNS: apex A/AAAA to the Worker, `www` 301 to apex, CAA record limiting issuers to Let's Encrypt and Google Trust Services (Cloudflare's), DNSSEC after cut-over, DMARC `p=none` → `p=quarantine` after 30 days, SPF, DKIM, MTA-STS and TLS-RPT (`_mta-sts`, `.well-known/mta-sts.txt`), BIMI optional later (needs a VMC, paid: skip).
26. Email links: `mailto:admin@matterofplace.com` rendered from `settings.site.contact.email`; unsubscribe and List-Unsubscribe headers on every newsletter (B11).

**H. Caching (architecture section 13, S52; B17 owns the CSP hashes and the cookie-free HTML and carries the other rules as tests)**
27. Every public read in this slice goes through `getPublicState` and `getCatalog` (B3), which take an injectable database client (F25 e): feeds, redirects, 410, flags (`csp_enforce`, `maintenance`), the contact email and imprint (`settings.site`). `public_state()` returns `catalog_version`, `flags`, `coming_soon_global`, `coming_soon_markets`, `site` and `illustrative_content`, and the snapshot carries `redirects` and `slug_history`; these key names are final (F25 b) and this slice reads `flags`, `site`, `redirects` and `slug_history` under those names. A write to `settings` (flags, `site`), `redirects` or `slug_history` bumps `catalog_version` by B2's triggers (F25 a), so the maintenance switch, `csp_enforce` and the imprint reach cached pages within 15 seconds; no code in this slice bumps the version. The cache key kinds are `html`, `json` and `doc` (F25 c): pages are `html`, the feeds and the generated text files are `doc`. No loader, route or feed handler in this slice queries a table on a request.
28. Cheap writes (rule 8): `csp-report` runs its in-memory rate limit before any database call, drops duplicates of the same directive and blocked URI within a minute, and stores the rest with one multi-row insert; `web_vitals` events join B3's browser batch (flush every 10 seconds and on `visibilitychange`, at most 20 per beacon) and have no beacon of their own.
29. The rendered HTML of a public page is byte-identical with and without a `mop_consent` cookie, a `Sec-GPC` header and any other cookie.

Events emitted: `web_vitals`, `consent_set`, `csp_report` (stored, not audited). Permissions: none (public surface); `settings.flags.maintenance` is admin only.

## Risks and gotchas (link GOTCHAS ids)
- CSP with TanStack Start: hydration scripts need their hashes in the policy (no nonce, section 13); enforce only after a week of clean reports (step 10). Turnstile needs its frame and script hosts.
- Self-hosting fonts changes rendering slightly; compare screenshots before and after (08-visual-pass tooling).
- HTML is cached at the edge and identical for every visitor (architecture section 13, S52), so the CSP uses hashes, never a per-request nonce: hashes are computed once at render on a cache miss and the finished policy header is stored with the entry by B3's cache module (F25 d). TanStack Start's dehydrated state is an inline script whose content differs per page, which is why the hash is per page and not per build; step 1 lists every inline script and style element of the six pages and records any that cannot be hashed (React `style` attributes would need `style-src-attr`, decided there and recorded in the runbook).
- Service worker must never cache the catalog or admin; scope it to `/` with an allow-list of the shell and error page only.
- Contrast: Warm Grey #8B877F on Warm Ivory #F5F2EB is about 3.6:1; body text in Warm Grey fails AA; use it only for large text or adjust the token (design decision recorded when the contrast script runs).
- G-006 (public env), G-007 (tokens only), P-009 (free tier: Observatory and PSI APIs are free but rate limited).
