# B17 — Website essentials and compliance (the must-haves of any professional site)

Lane: website · Stage: 3 · Owner agent: mop-builder (mop-designer for the icon set, error pages and consent notice) · Depends on: B1b (headers middleware, deploy), B3b (consent library, flags) · Unblocks: H1 (its checklist verifies every item here)

## Goal and observed exit
Every essential a serious publication site must have is present, measured and enforced, so that a privacy lawyer, a
security scanner, an accessibility auditor and a search engineer each find nothing missing. Observed exit: the
`essentials` test suite passes on the preview URL; `securityheaders.com` grade A; Mozilla Observatory A; Lighthouse
accessibility 100 and best practices 100 on six pages; the consent notice works with and without JavaScript; every
`.well-known` file resolves; RSS validates; the icon set renders on iOS, Android and Windows.

## Contract (inputs, outputs, invariants, events emitted, permissions)
Invariants, grouped. Each is a test in `tests/e2e/essentials.spec.ts` or `tests/unit/essentials.test.ts`.

**A. Security headers (served by the Worker on every response; B1b owns the middleware, this slice owns the values)**
1. `Content-Security-Policy` (enforced after two weeks report-only): `default-src 'self'; script-src 'self' 'nonce-<per-request>' https://challenges.cloudflare.com; style-src 'self' 'nonce-<per-request>'; img-src 'self' data: https://media.matterofplace.com; font-src 'self'; connect-src 'self' https://challenges.cloudflare.com; frame-src https://challenges.cloudflare.com; frame-ancestors 'none'; base-uri 'self'; form-action 'self'; object-src 'none'; upgrade-insecure-requests; report-to csp`. GA4/GTM hosts are added to `script-src`/`connect-src` only after consent, via the nonce'd loader. `Reporting-Endpoints: csp="/api/public/csp-report"`.
2. `Strict-Transport-Security: max-age=31536000; includeSubDomains` (preload added at day 30, L1).
3. `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`, `X-Frame-Options: DENY` (belt and braces with frame-ancestors), `Permissions-Policy: camera=(), microphone=(), geolocation=(), payment=(), usb=(), interest-cohort=()`, `Cross-Origin-Opener-Policy: same-origin`, `Cross-Origin-Resource-Policy: same-site`, `X-DNS-Prefetch-Control: off`.
4. Admin and API responses: `Cache-Control: private, no-store`; public pages `public, s-maxage=300, stale-while-revalidate=86400`; fingerprinted assets `public, max-age=31536000, immutable`; photographs `public, max-age=2592000`. `Vary: Accept` on image routes. `ETag` on JSON.
5. No third-party script or font loads before consent, and none at all except GA4/GTM after consent. Google Fonts are replaced by self-hosted WOFF2 with `font-display: swap` and `<link rel=preload>` for the two text faces (GDPR: no font requests to Google from EU visitors).
6. Every external script that survives (GA4 loader) has Subresource Integrity where the vendor supports a versioned URL; otherwise it is proxied through a first-party path with a pinned version.

**B. Privacy, cookies, consent (B3b owns the consent library; this slice owns the policy and the inventory)**
7. Cookie inventory kept in `docs/cookies.md` and rendered on `/cookies`: name, purpose, provider, duration, category (necessary / analytics). At launch the only cookies are the consent choice (`mop_consent`, 12 months, necessary) and Turnstile's; GA4 cookies exist only after consent.
8. Consent model: CCPA opt-out plus GDPR opt-in in one component: default is "no analytics" for everyone; the notice offers Accept / Decline / Settings; Global Privacy Control (`Sec-GPC: 1`) is honoured as Decline automatically; choice stored in the cookie and mirrored to `localStorage`; a "Privacy choices" link in the footer reopens it; consent version bumps when the inventory changes. Works without JavaScript (the notice is server-rendered, the links are real links).
9. No consent wall, no dark patterns: equal-weight buttons, no pre-ticked boxes, no "by continuing you agree".
10. Data subject requests: `/privacy-request` form (B16) posts to `subjects/request` (B3); acknowledgement within 10 days, fulfilment within 45 (CCPA) / 30 (GDPR) tracked in admin.
11. Legal pages (B16): Privacy (with CCPA section, categories, Do Not Sell or Share, GPC statement, retention table, contact), Cookies, Terms for Professionals, Accessibility statement, Imprint block in the footer (entity, address, contact). Last-updated dates on each. Linked from every page's footer.

**C. Accessibility (WCAG 2.2 AA)**
12. `lang="en"` and `dir` on `<html>`; a skip link to `main`; one `h1` per page; landmarks (`header`, `nav`, `main`, `footer`, `aside`); focus visible on every interactive element (2 px Obsidian outline offset 2 px on Bone, Bone on Obsidian); target size ≥ 24 px; colour contrast ≥ 4.5:1 for text (Warm Grey on Ivory is checked and adjusted where it fails); `prefers-reduced-motion` disables drift and fades; forms have labels, described errors, `aria-live` for notices; dialogs trap focus and restore it; images have alt (illustrative galleries use descriptive alt, decorative images empty alt); keyboard operable menu, search, gallery, filters; no content flashing; captions field on the film. axe serious/critical = 0 on every route in CI (B4).

**D. Discoverability and social (B13 owns structured data and sitemaps; this slice owns the rest)**
13. Per page: unique `<title>` (brand once, G-003), meta description 70 to 160 chars, canonical, Open Graph (`og:type`, `og:title`, `og:description`, `og:image` 1200×630 from B9 covers, `og:url`, `og:site_name`, `og:locale`), Twitter card `summary_large_image`, `theme-color`, `article:*` on stories.
14. `robots.txt` (dynamic route, B13), `sitemap.xml` index with pages and image sitemap, `llms.txt`, `llms-full.txt`, an RSS 2.0 feed at `/feed.xml` for properties and stories with autodiscovery `<link>`, JSON Feed at `/feed.json`.
15. Structured data (B13): `Organization` (logo, sameAs, contactPoint), `WebSite` with `SearchAction`, `BreadcrumbList`, `RealEstateListing`/`Residence`, `Article`, `FAQPage`, validated in CI.
16. Redirects table (B7) and slug history 301s (B3); `410 Gone` for taken-down properties; trailing-slash and `www` canonicalisation at the edge (one canonical host, apex).

**E. Identity files and icons**
17. Icon set from the emblem: `favicon.ico` (16/32/48), `favicon.svg` (with `prefers-color-scheme` variant), `apple-touch-icon.png` 180, `icon-192.png`, `icon-512.png`, `maskable-512.png`, `mstile-150.png`; `site.webmanifest` (name, short_name, icons, theme and background in Bone/Obsidian, `display: browser`); `browserconfig.xml`.
18. `/.well-known/security.txt` (RFC 9116: Contact admin@, Expires, Preferred-Languages, Canonical, Policy link), `/.well-known/change-password` (redirects to admin sign-in), `humans.txt` (credits, calm), `robots.txt` (B13). `ads.txt` deliberately absent (no ad inventory).
19. Error pages: branded 404 (search, links to markets), 410 (property taken down), 500 (calm, request id shown for support), 503 maintenance page switchable by `settings.flags.maintenance` with `Retry-After`; offline notice via a minimal service worker that caches only the shell and the error page (no offline catalog).

**F. Performance and delivery (B4 enforces budgets; this slice implements)**
20. Images: AVIF + JPEG variants, `srcset`/`sizes`, `loading="lazy"` below the fold, `fetchpriority="high"` on the hero, explicit `width`/`height` (no CLS), `decoding="async"`; video poster, `preload="none"`.
21. Fonts: self-hosted, subset to Latin, WOFF2, two faces preloaded, `font-display: swap`, `size-adjust` fallbacks to avoid CLS.
22. HTTP: Brotli (Cloudflare), HTTP/3 on, Early Hints (`103`) for the two fonts and the stylesheet, `preconnect` only to `media.matterofplace.com` and `challenges.cloudflare.com`.
23. JavaScript budget 150 KB (B4), no third-party tag before consent, route-level code splitting (TanStack already), `defer` on everything non-critical.
24. Uptime check (B14), Sentry (B1b), Web Vitals field data sent to first-party `analytics_events` (`web_vitals` event, anonymous) so the audit robot sees real LCP/CLS/INP.

**G. Domain and mail hygiene (L1 and B5 own the records; this slice owns the checklist)**
25. DNS: apex A/AAAA to the Worker, `www` 301 to apex, CAA record limiting issuers to Let's Encrypt and Google Trust Services (Cloudflare's), DNSSEC after cut-over, DMARC `p=none` → `p=quarantine` after 30 days, SPF, DKIM, MTA-STS and TLS-RPT (`_mta-sts`, `.well-known/mta-sts.txt`), BIMI optional later (needs a VMC, paid: skip).
26. Email links: `mailto:admin@matterofplace.com` rendered from `settings.site.contact.email`; unsubscribe and List-Unsubscribe headers on every newsletter (B11).

Events emitted: `web_vitals`, `consent_set`, `csp_report` (stored, not audited). Permissions: none (public surface); `settings.flags.maintenance` is admin only.

## Steps (ordered; each fits half a day; each ends with the command that proves it)
1. Header table and nonce middleware; report-only CSP; `csp-report` route. Proof: `curl -sI https://<preview>/ | grep -i -E "content-security|strict-transport|x-content|referrer|permissions|cross-origin"` shows every header; `bunx vitest run tests/unit/essentials.test.ts -t headers`.
2. Self-hosted fonts and preloads; remove the Google Fonts link. Proof: `curl -s https://<preview>/ | grep -c fonts.googleapis` → 0; Lighthouse "Ensure text remains visible" passes.
3. Icon set and manifest from the emblem; `__root.tsx` head links; identity files. Proof: `for p in /favicon.ico /favicon.svg /apple-touch-icon.png /site.webmanifest /.well-known/security.txt /humans.txt; do curl -s -o /dev/null -w "$p %{http_code}\n" https://<preview>$p; done` → all 200; `bunx web-manifest-validator public/site.webmanifest`.
4. Consent v2: Accept / Decline / Settings, GPC, no-JS route, `/cookies` page from the inventory, footer "Privacy choices" link. Proof: Playwright: with `Sec-GPC: 1` no GA request is made after load; with JS disabled the decline link sets the cookie; `bunx playwright test tests/e2e/essentials.spec.ts -g consent`.
5. Accessibility pass: skip link, landmarks, focus ring tokens, contrast fix, reduced motion, dialog focus trap, alt audit script. Proof: `bunx playwright test tests/e2e/a11y.spec.ts` → axe serious/critical 0 on every route; `node scripts/contrast.mjs` → all pairs ≥ 4.5.
6. Error pages (404, 410, 500, 503 maintenance) and the minimal service worker. Proof: `curl -s -o /dev/null -w "%{http_code}" https://<preview>/nope` → 404 with the branded body; flip `maintenance` on dev → 503 with `Retry-After`.
7. RSS and JSON feeds with autodiscovery. Proof: `curl -s https://<preview>/feed.xml | bunx feed-validator` (or the W3C validator API) → valid; `<link rel="alternate" type="application/rss+xml">` present.
8. Images and delivery: `srcset`, dimensions, `fetchpriority`, Early Hints list, Brotli and HTTP/3 confirmed at the zone. Proof: Lighthouse CI on six pages → performance ≥ 95, CLS < 0.1; `curl -sI --http3 https://<preview>/` → `HTTP/3 200`.
9. Web Vitals field beacon. Proof: `select count(*) from analytics_events where event='web_vitals'` > 0 after a browse on preview.
10. CSP enforce after a report-only week with zero unexpected reports: flip `csp_enforce`. Proof: `curl -sI ... | grep -i "content-security-policy:"` (not `-report-only`); no console CSP errors in the render gate.
11. DNS and mail hygiene checklist executed with L1 and B5: CAA, DNSSEC, DMARC ramp, MTA-STS, TLS-RPT. Proof: `dig CAA matterofplace.com +short`, `dig TXT _dmarc.matterofplace.com +short`, `curl -s https://matterofplace.com/.well-known/mta-sts.txt`.
12. External graders in CI: Mozilla Observatory ≥ A, securityheaders.com A (manual screenshot into H1). Proof: the `observatory` CI step output.

## Verification (commands and expected output; watched-fail for every new test)
- `bun run check` and `bun run build` green; `bunx vitest run tests/unit/essentials.test.ts` → all pass; `bunx playwright test tests/e2e/essentials.spec.ts tests/e2e/a11y.spec.ts` → all pass on preview.
- Watched-fail: (a) remove `X-Content-Type-Options` from the table → headers test red; (b) re-add the Google Fonts link → fonts test red; (c) set a decorative image alt to text → a11y test red; (d) break the RSS date format → feed test red; (e) send `Sec-GPC: 1` and force GA load → consent test red.
- Lighthouse CI: performance ≥ 95, accessibility 100, best practices 100, SEO 100 on `/`, `/properties`, a property, a market, `/exposure`, `/submit`.

## Risks and gotchas (link GOTCHAS ids)
- CSP with TanStack Start: hydration scripts need the nonce; enforce only after a week of clean reports (step 10). Turnstile needs its frame and script hosts.
- Self-hosting fonts changes rendering slightly; compare screenshots before and after (08-visual-pass tooling).
- Service worker must never cache the catalog or admin; scope it to `/` with an allow-list of the shell and error page only.
- Contrast: Warm Grey #8B877F on Warm Ivory #F5F2EB is about 3.6:1; body text in Warm Grey fails AA; use it only for large text or adjust the token (design decision recorded when the contrast script runs).
- G-006 (public env), G-007 (tokens only), P-009 (free tier: Observatory and PSI APIs are free but rate limited).

## Out of scope
Multi-language and hreflang; BIMI (paid VMC); full offline mode; ads.txt; third-party cookie banners or CMPs (we ship our own, no vendor); WCAG AAA.
