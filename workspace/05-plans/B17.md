## Goal and observed exit
Every essential a serious publication site must have is present, measured and enforced, so that a privacy lawyer, a
security scanner, an accessibility auditor and a search engineer each find nothing missing. Observed exit: the
`essentials` test suite passes on the preview URL (`https://pr-<n>.holy-meadow-4327.workers.dev`, E2) and on the local build (`bun run cf:preview`, `http://127.0.0.1:8788`; in this plan `<preview>` means either); `securityheaders.com` grade A; Mozilla Observatory A; Lighthouse
accessibility 100 and best practices 100 on six pages; the consent notice works with and without JavaScript; every
`.well-known` file resolves; RSS validates; the icon set renders on iOS, Android and Windows.

**A. Security headers (served by the Worker on every response; B1b owns the middleware, this slice owns the values)**
1. `Content-Security-Policy` (report-only first; H1 flips it to enforcing through `flags.csp_enforce`): `default-src 'self'; script-src 'self' <'sha256-...' for each inline script of the page> https://challenges.cloudflare.com https://*.googletagmanager.com; style-src 'self' <'sha256-...' for each inline style element of the page>; img-src 'self' data: <origin of env.MEDIA_BASE_URL, the one public media base of ASSUMED G3: `https://media.matterofplace.com` on production, the dev bucket's `r2.dev` URL on `mop-dev`; omitted while the variable is empty, which it is until R2 is on, E8> https://*.google-analytics.com https://*.googletagmanager.com; font-src 'self'; connect-src 'self' https://challenges.cloudflare.com https://*.google-analytics.com https://*.analytics.google.com https://*.googletagmanager.com <origin of SUPABASE_URL, for the browser's signed upload PUT in B3>; frame-src https://challenges.cloudflare.com; frame-ancestors 'none'; base-uri 'self'; form-action 'self'; object-src 'none'; upgrade-insecure-requests; report-uri /api/public/csp-report; report-to csp`. Framing exceptions, chosen by `cspFor`'s fourth argument `{ framing }`: a preview-token page (`/property/<slug>?preview=<token>` or `?draft_token=`, never cached, B7) sends `frame-ancestors 'self'` so B7's editor can show it in its Preview iframe, and an `/admin` document adds `'self'` to `frame-src`; every other response keeps `frame-ancestors 'none'`. `report-uri` stays beside `report-to` because browsers without the Reporting API send only to `report-uri`. The policy is by hashes and never by nonce (architecture section 13 rule 5, S52): HTML is cached and identical for every visitor, so a per-request nonce would be stale on every cache hit. `inlineHashes(html)` in `headers.ts` computes the SHA-256 of every inline script and style element of a rendered page once, at render on a cache miss, and `cspFor(env, flags, hashes)` builds the finished policy header from them; `withPageCsp(render, env, flags)` (new export in `headers.ts`) wraps `deps.render` inside `handle` in `src/server/lib/pipeline.ts`, buffers the body of a 200 `text/html` response, calls `inlineHashes(html)` and sets the policy header on that response (F26 d: the render sets the header), and B3's `cachedResponse` stores that header (`Content-Security-Policy-Report-Only` while report-only, `Content-Security-Policy` once enforcing) with the page's cache entry (F25 d), so a hit and a miss of one page carry the same policy and a hit does no hashing. The other security headers and `x-request-id` are added after the lookup by B1b's middleware and are never stored. A flip of `csp_enforce` is a write to `settings`, which B2's trigger turns into a new `catalog_version` (F25 a), so the next render stores the enforcing header under a new key. The GA4 hosts (gtag.js is served from `www.googletagmanager.com`; there is no Tag Manager container, ASSUMED G41) are in `script-src`/`connect-src` for every visitor (the policy cannot depend on consent without varying the response); nothing loads from them before consent, because the loader is a first-party file (B13's `Ga4Loader` calling `loadGa4` in `src/lib/ga4.ts`) that injects the tag only after `readConsent()` says analytics. `Reporting-Endpoints: csp="/api/public/csp-report"`. B1b creates `securityHeaders(env, flags)` and `cspFor(env, flags, scriptHashes = [])` (a hash slot from the start, never a nonce) and ships `Content-Security-Policy-Report-Only` with the Google Fonts rows; this slice fills the table values, adds `inlineHashes(html)`, `withPageCsp` and the optional `{ framing }` argument, removes the Google Fonts hosts (step 2) and adds the tests that `cspFor` output carries no Google Fonts host and no `nonce-` source.
2. `Strict-Transport-Security: max-age=31536000; includeSubDomains` until preload day 30; then L1 raises it to `max-age=63072000; includeSubDomains; preload`.
3. `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`, `X-Frame-Options: DENY` (belt and braces with frame-ancestors; `SAMEORIGIN` on preview-token pages, matching invariant 1), `Permissions-Policy: camera=(), microphone=(), geolocation=(), payment=(), usb=(), interest-cohort=()`, `Cross-Origin-Opener-Policy: same-origin`, `Cross-Origin-Resource-Policy: same-site`, `X-DNS-Prefetch-Control: off`.
4. Cache-Control per route class, following architecture section 13. One owner per layer: the browser-facing value comes from B1b's `browserCacheControl(kind)` in `src/server/lib/pipeline.ts` (this slice adds no row to that function's table: the feeds are kind `doc` like the sitemap, and the identity route files are not stored and set their own header in their handler; static files, `/sw.js` included, take theirs from `public/_headers`), the never-cached rule is B1b's `neverCached`, and the edge lifetime of a stored copy (`s-maxage`, `stale-while-revalidate`) is set by B3's `cachedResponse` in `src/server/public/cache.ts`; `headers.ts` sets no Cache-Control. The values: `/api/hooks/*`, every POST, every write under `/api/public/`, preview-token pages, any response with `Set-Cookie` and every 5xx carry the `no-store` that B1b's `neverCached` forces (architecture 13 rule 6); B7's admin responses (`/admin`, `/api/admin/*` through `adminJson`) and this slice's own `/api/consent` answer and 503 maintenance answer set `private, no-store` themselves, and on these never-cached classes B1b's pipeline replaces whatever `Cache-Control` the handler set with exactly `no-store` (set, not merged, ASSUMED G65); every test and proof in this slice for these classes asserts that `Cache-Control` contains the directive `no-store`, never an exact string; public pages `public, max-age=0, must-revalidate` to the browser (B1b, unchanged) with the stored copy held at `s-maxage=300, stale-while-revalidate=86400` (B3); 404 and 410 pages stored at `s-maxage=60`; catalog JSON `public, max-age=60` in the browser with the same edge lifetime as pages; `/sw.js` `no-cache`; `robots.txt`, `sitemap.xml`, `llms.txt` and `llms-full.txt` `public, max-age=3600, s-maxage=3600, stale-while-revalidate=86400` (kind `doc`; B13's handlers pass the `edge` argument `{ sMaxAge: 3600, staleWhileRevalidate: 86400 }` to `cachedResponse`, asserted by B13's `seo-cache.test.ts`); the feeds `/feed.xml` and `/feed.json` `public, max-age=3600, s-maxage=3600` (kind `doc`, B1b's `browserCacheControl("doc")` and B3's `doc` default `{ sMaxAge: 3600 }`); `/.well-known/security.txt` and `/.well-known/mta-sts.txt` `public, max-age=3600`, set by their own handler and never stored; `/.well-known/change-password` `no-store`; fingerprinted assets `public, max-age=31536000, immutable`; bundled `/media/*` and `/fonts/*` one week (`max-age=604800`, `public/_headers`); R2 photograph variants under content-hashed keys `public, max-age=31536000, immutable` once R2 is on. No response negotiates the image format, so no response carries `Vary: Accept`: the browser picks AVIF or JPEG from the `<picture>` sources of invariant 20, and there is no image route in the Worker (bundled images are static assets, photographs are R2 objects). `ETag` on JSON. No public response carries `Vary: Cookie` and none depends on a cookie or a request header (rule 5).

**H. Caching (architecture section 13, S52; B17 owns the CSP hashes and the cookie-free HTML and carries the other rules as tests)**
27. Every public read in this slice goes through `getPublicState` and `getCatalog` (B3), which take an injectable database client (F25 e): feeds, redirects, 410, flags (`csp_enforce`, `maintenance`), the contact email and imprint (`settings.site`). `public_state()` returns the seven keys of G39 (`catalog_version`, `flags`, `coming_soon_global`, `coming_soon_markets`, `site`, `illustrative_content`, `og_static`), and the snapshot carries `redirects` and `slug_history`; these key names are final (F25 b) and this slice reads `flags`, `site`, `redirects` and `slug_history` under those names. A write to `settings` (flags, `site`), `redirects` or `slug_history` bumps `catalog_version` by B2's triggers (F25 a), so the maintenance switch, `csp_enforce` and the imprint reach cached pages within 15 seconds; no code in this slice bumps the version. The cache key kinds are `html`, `json` and `doc` (F25 c): pages are `html`, the feeds and the generated text files are `doc`. No loader, route or feed handler in this slice queries a table on a request.
28. ## Risks and gotchas (link GOTCHAS ids)
- CSP with TanStack Start: hydration scripts need their hashes in the policy (no nonce, section 13); enforce only after a week of clean reports (step 10). Turnstile needs its frame and script hosts.
- Self-hosting fonts changes rendering slightly; compare screenshots before and after (08-visual-pass tooling).
- HTML is cached at the edge and identical for every visitor (architecture section 13, S52), so the CSP uses hashes, never a per-request nonce: hashes are computed once at render on a cache miss and the finished policy header is stored with the entry by B3's cache module (F25 d). TanStack Start's dehydrated state is an inline script whose content differs per page, which is why the hash is per page and not per build; step 1 lists every inline script and style element of the six pages and records any that cannot be hashed (React `style` attributes would need `style-src-attr`, decided there and recorded in the runbook).
- Service worker must never cache the catalog or admin; scope it to `/` with an allow-list of the shell and error page only.
- Contrast: Warm Grey #8B877F on Warm Ivory #F5F2EB is about 3.6:1; body text in Warm Grey fails AA; use it only for large text or adjust the token (design decision recorded when the contrast script runs).
- G-006 (public env), G-007 (tokens only), P-009 (free tier: Observatory and PSI APIs are free but rate limited).
- Shared files: `src/lib/strings.ts`, `src/routes/__root.tsx`, `src/services/types.ts` and `src/components/layout/footer.tsx` are edited in the order B3, B3b, B5, B17, B16 (ASSUMED G33, which replaces F21). B17 edits them after B5 has landed (B5 is in the same wave) and before B16 starts; never in parallel with either.
- The maintenance switch on `mop-dev` takes down every preview and local build that reads `mop-dev` for as long as it is on: step 6 flips it only through `scripts/with-maintenance.ts`, which holds the `mop-dev-tests` advisory lock (ASSUMED G34) and restores the value in a `finally`, so it lasts at most the 16 second wait.
- GA4 and Turnstile scripts cannot carry Subresource Integrity (invariant 6); the CSP host list is the only control on them.
- G-014, P-015 (Git Bash rewrites `/path` arguments; step 3 uses `MSYS_NO_PATHCONV=1` and `%{url_effective}`).
